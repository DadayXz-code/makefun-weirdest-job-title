A tiny deterministic Python program that writes one gloriously weird job title — "Senior Penguin Apology Letter Ghostwriter" (41 characters) — to `/output/entry.txt` for make.fun's Weirdest Job Title: Blind Judge Showdown bounty. A real-sounding senior role with one hilariously specific twist: the clients are penguins, and the work is apology letters. Standard library only, no network, no randomness: the same title on every run.

## Run it

```sh
python3 main.py
```
